# BoxPlayer v5.0.25

## 中文

### 网盘与传输

- 修复多网盘文件夹的分页续页与失败恢复，避免目录只显示首批文件。
- 改善启动时网盘根目录加载的重试与恢复；百度网盘从桌面拖入文件时会使用当前目录作为上传目标。
- 为 Aria2 WebSocket 错误增加处理，连接异常不会再造成未处理错误。

### 媒体与资料库

- 修复使用反向代理子路径的 Emby 播放地址，避免请求丢失代理路径而出现 404。
- 改善视频、音乐和书籍扫描的分页、去重、失败状态恢复与元数据补全流程。

### 使用体验

- 支持识别剪贴板中的常见网盘分享链接：可直接导入的链接会进入导入流程，其余链接会交由浏览器打开。
- 提升分栏拖拽线在浅色与深色主题下的可见性。

### 分析

- 修复正式发布包遗漏 PostHog 项目 Key 与 Host 的问题，确保安装版能够上报启动与诊断事件。

## English

### Cloud drives and transfers

- Fixed continuation and recovery for paginated folder listings across cloud drives, preventing folders from showing only the first batch of files.
- Improved startup root-folder loading and recovery. Drag-and-drop uploads to Baidu Netdisk now retain the current destination folder.
- Added Aria2 WebSocket error handling so connection failures no longer surface as unhandled errors.

### Media and libraries

- Fixed Emby playback URLs behind reverse-proxy subpaths, preventing missing-path 404 errors.
- Improved pagination, deduplication, failure recovery, and metadata enrichment for video, music, and book scans.

### Experience

- Recognizes common cloud-share links from the clipboard: supported imports enter the import flow, while other links open in the browser.
- Improved split-pane divider visibility in both light and dark themes.

### Analytics

- Fixed missing PostHog project key and host in release builds so installed clients can report startup and diagnostic events.
