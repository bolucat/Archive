# BoxPlayer v5.0.13

## 更新内容

- 修复关闭“开机自动检测更新”后仍会后台检测、静默下载的问题；手动“检查更新”不受此设置影响，更新源不可用时仍会回退到 GitHub 原生地址。
- 修复电子书打开链路：EPUB 在所有已支持网盘中统一进入阅读器；百度网盘阅读和下载会携带必要的 User-Agent 与 Referer 请求头。
- 完善多网盘上传分流与能力边界，避免不支持上传的网盘错误落入阿里云盘上传实现。
- 改进 115 分片上传的会话、令牌与断点续传处理，并补齐 OSS 上传辅助逻辑。
- 改进 123、百度、夸克、光鸭、Dropbox、OneDrive、Box 和 Google Drive 的上传实现及相关校验。
- 修复属性页对只读网盘能力的展示边界，并补充各网盘上传与能力声明的回归测试。
- 更新 Electron 原生模块重建命令，便于在 Electron 版本变更后重新编译 better-sqlite3。

## Fixes / English

- Fixed background update checks and silent downloads continuing after the startup update-check setting is disabled. Manual checks remain available and fall back to the native GitHub feed when needed.
- Fixed cloud book opening: EPUB files now route to the reader for every supported provider, and Baidu downloads keep the required User-Agent and Referer headers.
- Hardened provider-specific upload routing, multipart resume handling, and capability boundaries across 115, 123, Baidu, Quark, Guangya, Dropbox, OneDrive, Box, and Google Drive.
- Added regression coverage for update behavior, cloud-book download headers, upload flows, resumable upload tokens, and provider capability rules.
