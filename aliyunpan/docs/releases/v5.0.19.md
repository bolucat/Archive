# BoxPlayer v5.0.19

## 中文

### 阅读器体验

- 阅读设置可按单本书保存；关闭“独立样式”会移除该书的专属设置，且可一键恢复默认阅读样式。
- 增加自动滚动阅读：滚动模式平滑向下阅读，分页模式会按页自动前进。
- PDF 支持透明背景、反色阅读，并可导出可提取的文字为 TXT 文件。
- 优化正文宽度与横向页边距，避免单页模式出现不必要的空白和相邻页面露出。
- 页眉、页脚和页框可独立隐藏；调整了其字号、间距与数字对齐，底部进度区域更清晰。
- 阅读器会更可靠地识别已有阅读位置；没有保存位置的书籍从第一章开始。
- 选中单个词时可直接进入词典查询；自定义 CSS 和字体样式会正确应用到重新渲染后的页面。

## English

### Reader experience

- Reader settings can now be saved per book. Turning off separate styles removes that book’s override, and defaults can be restored in one action.
- Added auto-scroll reading: scroll layouts advance smoothly, while paginated layouts turn pages automatically.
- PDFs support transparent backgrounds and inversion, and extractable text can be exported as a TXT file.
- Improved content width and horizontal margins to prevent excessive whitespace and exposed adjacent pages in single-page mode.
- Headers, footers, and page borders can be hidden independently. Their typography, spacing, and numeric alignment were refined, with a clearer bottom progress area.
- Existing reading positions are detected more reliably; books without a saved position open at the first chapter.
- Selecting a single word can open dictionary lookup directly. Custom CSS and font overrides now apply correctly after a page rerender.
