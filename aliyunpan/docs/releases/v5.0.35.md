# BoxPlayer v5.0.35

本次更新重点重构了聚合媒体库：将网盘、本地文件与媒体服务器集中到一个「媒体库」入口，以统一的首页、导航和浏览方式管理分散在不同来源中的内容。

![BoxPlayer 聚合媒体库首页预览](https://raw.githubusercontent.com/gaozhangmin/boxplayer/beac66e576a468d649f0683369dda4fbc81f91b2/docs/releases/assets/v5.0.35-aggregated-media-library.png)

## 重构的聚合媒体库

### 一个入口，连接多个媒体来源

- 将视频库、媒体服务器、音乐和书籍入口整合到统一侧栏，减少在不同顶栏页面之间切换。
- 在同一媒体库中浏览已配置的网盘与本地媒体，以及 Emby、Jellyfin、Plex 服务器；保留各来源独立的连接与内容管理。
- 整合来源快捷入口和文件夹浏览，支持列表与网格视图，并提供播放、循环播放及适用内容的随机播放操作。
- 兼容原有启动页面设置，原媒体服务器、音乐和书籍入口会转到对应的媒体库分区。

### 更完整、可定制的媒体首页

- 汇集网盘、本地媒体和媒体服务器的「继续观看」，并展示各来源的最近添加、服务器待续看等内容。
- 提供电影、电视剧、未观看、未匹配、类型等浏览入口，以及音乐和书籍分区。
- 新增每日推荐与高分电影栏目：根据 TMDB 榜单匹配库内已有媒体，方便从自己的收藏中发现值得观看的内容。
- 首页管理支持调整栏目与来源的顺序、名称和显示状态；个性化设置会在本机保存。
- 可分别控制来源在媒体库与首页中的显示，隐藏或暂时不可用的来源仍可在管理界面中调整。

### 统一浏览与媒体操作

- 搜索入口支持选择刮削媒体库、本地文件或指定媒体服务器的搜索范围。
- 完善媒体排序：刮削媒体支持名称、文件名、添加时间和上映日期；媒体服务器提供评分、年份、时长等更多排序字段，支持升序与降序。
- 统一海报菜单与已观看标记，按媒体类型和来源能力提供播放、收藏、下载、分享、元数据刷新等操作。
- 增加个人评分与自定义合集管理；个人评分独立于公共评分，自定义合集支持关联不同媒体服务器的条目。
- 简化媒体服务器添加表单，改进地址、端口和 HTTPS 输入处理。

## 元数据刮削与媒体保留

- 修复重新刮削时旧剧集、视频版本或合集成员被覆盖的问题；保留手动修正和已有播放记录。
- 区分电影和电视剧的 TMDB ID，避免同号条目相互覆盖；收紧剧集匹配条件，减少相似名称误合并。
- 修复重叠目录扫描的来源关联，未匹配媒体现在会在后续增量扫描中重试。
- 改进文件夹季数、数字集数、多集合并文件和数字电影名的识别。
- 扫描账户失效或媒体库读取失败时不再当成空目录或成功结果。

## 媒体详情页改版

- 重新设计媒体服务器与网盘媒体库详情页，采用统一的沉浸式海报背景、内容层级和暗色视觉。
- 加大 Hero 海报可见区域，并将播放按钮、视频版本选择和操作按钮调整到更清晰的位置。
- 播放与版本选择区域和下方操作按钮组保持等宽；操作按钮会按照实际数量自动等分宽度并保留固定间距。
- 网盘媒体库详情页新增视频、字幕媒体信息卡片，切换视频版本时同步更新对应的文件与字幕信息。
- 类型、制作年份和地区标签移动到演员区上方，详细信息独立放置在页面底部。
- 评分统一使用 TMDB 标识，媒体服务器详情页不再显示播放列表操作。

## 内置 MPV：修复播放卡顿，改进画面流畅度

针对此前内置 MPV 播放不流畅、画面停滞及播放窗口偶发卡死的问题，本次重点调整了原生渲染和画面传输链路。

- 移除 Windows / Linux 软件渲染路径中每 50 毫秒才处理一帧的限制。此前这一限制将画面输出压到约 20 FPS，导致 24、30、60 FPS 视频出现明显卡顿；现在按 MPV 请求处理画面帧。
- 减少画面传输与显示过程中的整帧内存复制，优化 Windows 硬件解码回拷路径，降低逐帧处理开销。
- 改进共享纹理和画面缓冲区的占用、复用与释放，避免尚在显示的资源被提前复用；完善播放器宿主生命周期处理。
- 改进播放状态、缓冲状态和错误反馈，首次画面加载超时时显示明确提示，避免持续停留在无反馈的加载状态。

以上为本次代码修复与优化内容，不代表所有平台、片源及硬件组合均已完成流畅度验证。

## 暗色模式、网盘播放与字幕

- 修复暗色模式中海报、背景图和人物图片占位仍显示亮色的问题。
- 改进本地 `data:` / `blob:` 图片在媒体服务器图片缓存流程中的兼容性。
- 调整网盘直链播放路径：普通未加密视频将提供商 URL 及必要请求头一起传给 MPV，Quark 保留提供商专用代理，加密视频仍使用本地解密代理。
- 同目录云字幕保留提供商所需的请求头；避免同一字幕轨道同时作为主、副字幕，并改进双字幕位置计算。
- 统一音乐、书籍分区的空状态与主题表现，修复书籍点击打开时被上次阅读恢复逻辑覆盖的问题。

## 其他修复与回归覆盖

- 修复阿里云上传重名自动重命名时误用已有文件的问题，冲突重试不再删除原有文件。
- 扩展聚合媒体库、刮削合并、来源关联、下载请求头和字幕的回归测试，并将媒体库回归检查加入发布流水线。
- 增加媒体服务器和网盘媒体详情页的 Electron Playwright 回归测试。
- 覆盖 Hero 海报高度、版本按钮位置、操作按钮自适应、TMDB 标识、暗色占位、媒体信息卡片和详情区块顺序。

## English

### Rebuilt aggregated media library

- A single Library entry now brings together scraped cloud/local media, Emby, Jellyfin, Plex, music and books, with shared navigation and source shortcuts.
- The home page combines continue-watching items and source-specific shelves. Daily recommendations and top-rated movies match TMDB rankings against titles already in your library.
- Customize shelf and source order, names and visibility, with preferences saved locally.
- Choose a search scope, browse in grid or list views, and use expanded sorting and source-aware poster actions.
- Added personal ratings and custom collection management, including collections referencing items from different media servers. Existing startup-section preferences remain supported.
- Simplified server setup and improved address, port and HTTPS handling.

### Scraping and media retention

- Merge existing episodes, file variants and collection members during scraping while preserving manual edits and playback records.
- Separate movie/TV identities, tighten series matching and improve season, numeric episode and multi-episode recognition.
- Correct overlapping-folder source membership and retry unmatched media in later incremental scans.
- Report account, folder and library-read failures rather than treating them as empty or successful scans.

### Media detail redesign

- Redesigned media-server and scraped cloud-library detail pages with a shared cinematic dark layout.
- Increased visible hero artwork and aligned playback, version selection, and action controls.
- Action buttons now share the playback row width and automatically divide the available space while keeping fixed gaps.
- Added video and external-subtitle information cards to scraped media details; cards update with the selected video version.
- Moved genre, year, and region tags above the cast section and placed detailed file information at the bottom.
- Standardized ratings on the TMDB logo and removed playlist actions from media-server details.

### Embedded MPV: playback stutter and rendering improvements

- Removed a 50 ms frame throttle in the Windows/Linux software-rendering path that capped presentation at approximately 20 FPS and caused stutter with 24/30/60 FPS videos.
- Reduced full-frame memory copies and improved Windows hardware-decoding copy-back to lower per-frame overhead.
- Improved shared-texture/buffer ownership, reuse and release, along with player-host lifecycle handling.
- Improved playback/buffering state and error feedback, including an explicit first-frame loading timeout.
- These describe code fixes and optimizations, not completed smoothness validation for every platform, source and hardware combination.

### Dark mode, cloud playback and subtitles

- Fixed light image placeholders appearing in dark mode.
- Preserved renderer-local `data:` and `blob:` images through the media-server image cache.
- Ordinary unencrypted streams now pass provider URLs and required headers directly to MPV; Quark retains its provider-aware proxy, while encrypted videos continue to use the local decryption proxy.
- Improved bilingual subtitle selection and positioning.
- Preserved provider headers for same-directory cloud subtitles and unified music/book empty states and theme styling.

### Other fixes and regression coverage

- Fixed Aliyun upload-name conflict handling without deleting existing files, and corrected explicit book-opening behavior.
- Expanded library, scraping, source-membership, detail-layout, playback-header and subtitle regression coverage; added library checks to the release pipeline.
