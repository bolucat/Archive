## BoxPlayer v5.0.8

### 新功能 / New

- 新增简体中文与 English 界面语言，可在「设置 → 应用设置」即时切换。
- 重构设置中心的信息分组与视觉层次，上传冲突策略集中到上传设置。
- Added Simplified Chinese and English interface languages with instant switching in Settings.
- Refined the settings center hierarchy and moved upload-conflict behavior into Upload settings.

### 修复 / Fixes

- 修复未知分类的 MKV 文件无法进入播放流程的问题。
- 修复 GitHub 更新代理仍指向失效镜像的问题；后台更新与手动安装包链接均使用 gh-proxy 格式。
- 修复上传时重复显示确认窗口的问题，按已保存的同名文件策略自动入队。
- 修复隐藏顶部标签时访问 `checked` 属性报错的问题。
- 改进夸克网盘下载与预览请求的请求头透传，避免 403 拒绝访问。
- Fixed MKV playback routing when a provider reports an unknown file category.
- Fixed update proxy URLs and aligned background updates with gh-proxy.
- Fixed repeated upload-confirmation dialogs by applying the saved conflict policy automatically.
- Fixed the hidden top-tabs settings error and improved Quark download/preview request handling.
