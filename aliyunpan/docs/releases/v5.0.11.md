## BoxPlayer v5.0.11

### 更新内容

- 新增媒体元数据人工纠错：可从海报右键菜单或详情页搜索 TMDB 并重新匹配电影；电视剧支持整部剧、单季和单集范围的元数据修正。
- 重新设计元数据编辑窗口，使用海报列表展示候选标题、年份和详细信息；手动编辑结果会持久化，并在后续扫描时得到保留。
- 统一视频、音乐和书籍媒体库的文件源身份、扫描归属和删除语义。删除文件源会清理仅属于该源的条目，共享条目继续保留，并兼容迁移历史扫描数据。
- 修复扫描期间“查看全部”只显示扫描状态的问题；已有媒体可以继续浏览，新结果增量写入媒体库。
- 改进媒体库导航、快速搜索、详情页操作菜单、书籍页标题区和跨页面字号/间距一致性。
- 统一视频文件名清洗与 TMDB 匹配输入：本地和网盘扫描共用单次标准化结果，支持季目录、更多季集格式和技术标签，并修复 `Se7en`、`1917`、中文续集等误判。
- 收敛 clouddrive-cli 的工具与计划模型，移除重复的媒体整理实现，统一使用结构化计划 schema。
- BoxPlayer 网站现在可直接下载最新 GitHub Release 安装包，并通过 gh-proxy 加速 Windows、macOS 和 Linux 下载。

### English

- Added manual media metadata correction. Search TMDB and rematch movies from poster context menus or detail pages; TV shows support whole-show, season, and episode scopes.
- Redesigned the metadata editor around poster-list results with titles, years, and detailed metadata. Manual edits are persisted and preserved by later scans.
- Unified source identity, scan membership, and deletion semantics across video, music, and book libraries. Removing a source deletes source-only items, preserves shared items, and migrates legacy scan data.
- Fixed the “view all” flow during active scans so existing media remains browsable while new results are persisted incrementally.
- Improved media navigation icons, quick search, detail actions, the book-library header, and typography/spacing consistency across pages.
- Unified video filename normalization and TMDB matching inputs across local and cloud scans, including season-folder context, more episode formats, technical tags, and ambiguous titles such as `Se7en`, `1917`, and numbered Chinese sequels.
- Simplified clouddrive-cli tools and planning models by removing duplicate media-organizer implementations and using shared structured plan schemas.
- The BoxPlayer website now downloads the latest GitHub Release installers directly through gh-proxy for Windows, macOS, and Linux.
