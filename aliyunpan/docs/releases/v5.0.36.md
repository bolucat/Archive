# BoxPlayer v5.0.36

本次更新集中完善统一媒体库与音乐体验：统一各页面海报与详情页布局，改进首页和文件来源的拖动排序，补齐系列、播放列表与分类浏览；音乐库改为歌曲、歌手、专辑和自建歌单入口，并改进粒子播放器的切换；Trakt 支持系统浏览器登录、待看列表和个人评分同步。

## 统一媒体库与首页管理

- 主屏幕、分类、搜索结果和媒体服务器列表采用统一的海报尺寸、圆角、标题与年份布局，改进封面清晰度。
- 收藏夹使用彩色卡片，音乐、书籍与媒体服务器显示对应图标；补齐系列入口并去掉重复的收藏夹管理项。
- 首页管理支持拖动整行调整顺序，保存栏目顺序和显示设置；二级管理页面与一级页面保持一致宽度。
- 文件来源列表可直接拖动右侧手柄进行整行排序；网格选择「重新排序」后显示卡片抖动提示。
- 媒体库初次加载显示加载指示，改进空状态，删除列表顶部多余的说明文字。
- 修正继续观看卡片的本地进度比例，卡片底部显示清晰的橙色播放进度条。

## 媒体详情与分类浏览

- 扩大详情页背景图展示区域，去掉右侧独立圆角容器，统一底部内容对齐与按钮圆角。
- 修复暗色模式无背景图时出现白色区域的问题，调整简介与评分的间距。
- 有历史进度时，播放按钮显示进度及「继续：时间」提示。
- 媒体库与媒体服务器的集封面中央增加播放入口，简化重复的季标题。
- 系列和播放列表共用选择弹窗；海报菜单与详情页使用相同的选择界面，更多操作收纳到下拉菜单。
- 改进类型、年份、地区和演员的分类筛选与页面标题，从分类页返回时恢复原详情页。
- 移除媒体库详情页底部冗余的「详细信息」区块。

## 音乐库与粒子播放器

- 音乐库提供歌曲、歌手、专辑与我的歌单四个入口，支持搜索、创建歌单及从列表播放。
- 播放歌曲或「播放全部」时进入粒子播放器；返回音乐库后仍可通过底部播放条控制和再次进入。
- 修正队列标题显示全部歌曲、弹窗却只展示当前歌曲附近少量曲目的问题；现在可以滚动查看完整队列。
- 改进音乐元数据与封面展示，并保留歌词、音效及粒子可视化设置。

## Trakt 登录与同步

- 点击 Trakt 图标后直接打开系统浏览器授权，并通过应用回调完成登录。
- 登录后可将待看列表增删和个人评分同步到 Trakt；操作期间显示加载反馈，菜单按当前状态切换加入或移除。
- 账户弹窗展示用户名、头像、观看统计、同步开关与退出登录；修复弹窗宽度跳变和头像加载时的白色占位。
- 登录凭据由主进程加密保存；Trakt client_id 统一从本地环境配置和 GitHub Secrets 注入。

### 本次草稿重构建补充

- 首页管理采用三横线手柄、显示项目标题与橙色恢复按钮；调整指针捕获，避免移动行时意外取消拖动。
- Trakt 右上角入口仅在主屏幕显示，其他页面隐藏。
- 媒体服务器演员照片缺失或加载失败时使用人物头像图标。
- 补充海报评分、内容分级及列表信息，统一列表/网格模式记忆，并更新继续观看占位与进度显示。
- 向上拖动排序尚未完成真实应用验收，仍需验证；不得将单元测试通过视为该交互已验收。

- 本版本以 draft release 形式准备，安装包由发布流水线执行检查和构建后上传，最终由维护者手动公开发布。
- 「即将播放」为空的问题仍在核对：当前已配置 Emby 用户的 NextUp 与继续播放接口返回 0 条，移除时间过滤后结果相同，本版本不将该问题列为已修复。

## English

- Unified poster sizing, rounded corners, artwork quality, and titles across the home page, categories, search results, and media-server libraries.
- Added full-row drag sorting for home management and file sources, with an animated reorder mode for source cards.
- Refined immersive details, dark-mode artwork fallbacks, resume progress, episode play buttons, and navigation back from genre or cast results.
- Shared collection/playlist pickers between detail actions and poster menus; corrected music, books, favorites, and series entries.
- Added provider-specific server icons and endpoint management for alternate connection addresses.
- Trakt authorization opens the system browser. Signed-in users can update their watchlist and personal ratings, view account details, and control synchronization.
- The music library now offers songs, artists, albums, and personal playlists; playback opens the particle player and the full queue remains scrollable.
- The reported empty Emby Next Up result remains under investigation; it is not claimed as fixed in this release.
