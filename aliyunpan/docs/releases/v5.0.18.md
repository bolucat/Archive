# BoxPlayer v5.0.18

## 中文

### 文档 AI：从“打开文件”到“基于来源的对话”

- 在 PDF、EPUB、TXT、Markdown、DOCX 等支持预览的文档中，点击 **BoxPlayer AI / 用 AI 分析**，即可围绕当前文件进行总结和追问。
- 可从网盘文件列表、文件夹或搜索结果中选择最多 10 份文档，在同一个对话中比较、总结和提问。
- 提供“总结这些来源”“关键要点”“如何改进”“下一步”等快捷问题，也支持直接输入问题；`@文件名` 可明确引用已添加的来源。
- 回答实时生成，附带可查看的引用片段；PDF 引用可跳转回对应位置。支持复制回答、清空会话、反馈，以及切换到宽视图继续对话。
- 文档仅在本机进行解析、分块和索引，AI 只接收与问题相关的检索片段。图片型 PDF 暂不进行 OCR，无法提取文字时会明确提示。

### AI 工作台与阅读体验

- 新增 AI 工作台会话与任务持久化，文档阅读、网盘检索和文件操作可在同一上下文中衔接。
- PDF 阅读器增加连续阅读进度保存与恢复，并支持从 AI 引用位置回到文档。
- 优化文档预览、全局搜索及文件菜单中的“用 AI 分析”入口。

### 播放、字幕与媒体库

- 播放器增强多语言字幕识别与选择，修复来源账号、代理请求头和同目录字幕加载问题。
- 扫描媒体库时按网盘接口限速与队列处理，减少高频请求触发限流。
- 视频与音乐播放界面进一步同步字幕、弹幕和沉浸式舞台状态。

### 书籍与系统集成

- 书籍库支持同作品多格式归并、外部图书元数据补全、漫画阅读模式，以及更可靠的独立窗口阅读进度恢复。
- Windows、macOS 已注册视频、音频、电子书文件关联，可从系统双击文件直接用 BoxPlayer 打开。

## English

### Document AI: from file preview to grounded conversations

- Open a supported PDF, EPUB, TXT, Markdown, or DOCX file and choose **BoxPlayer AI / Analyze with AI** to summarize and ask questions about the current document.
- Select up to ten documents from cloud-drive lists, folders, or search results to compare, summarize, and query them in one conversation.
- Use quick prompts such as “Summarize these sources,” “Key takeaways,” “How can this be improved?”, and “Next steps,” or ask anything directly. Type `@filename` to explicitly reference an added source.
- Responses stream in real time with inspectable citations. PDF citations can jump back to the referenced location. You can copy responses, clear the conversation, send feedback, or continue in a wider modal view.
- Documents are parsed, chunked, and indexed locally. Only relevant retrieved excerpts are sent to the AI provider. Image-only PDFs are not OCRed yet and clearly report when no text can be extracted.

### AI workspace and reading

- Added persistent AI Workspace sessions and tasks so document reading, drive search, and file operations share one working context.
- PDF reading now saves and restores continuous progress, including jumps from AI citations back into the document.
- Improved the **Analyze with AI** entry points in document preview, global search, and file menus.

### Playback, subtitles, and media library

- Improved multilingual subtitle recognition and selection, including source-account context, proxy headers, and same-folder subtitle loading.
- Cloud media scans now use provider request queues and rate limiting to reduce throttling.
- Video and music experiences better synchronize subtitles, danmaku, and immersive-stage state.

### Library and system integration

- The book library now groups format variants, enriches books with external metadata, adds comic reading mode, and more reliably restores independent reader-window progress.
- Windows and macOS file associations now open video, audio, and ebook files directly in BoxPlayer.
